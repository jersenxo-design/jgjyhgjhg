QalaPass — учебный многостраничный сайт афиши и туров

Файлы:
- index.html — главная страница
- events.html — афиша с поиском, фильтрами и избранным
- tours.html — каталог туров + демо-форма бронирования
- event.html — отдельная страница события
- about.html — о проекте и контакты
- styles.css — адаптивный дизайн, анимации и оформление
- app.js — фильтры, переключение языка, избранное, модальные формы

Как открыть:
1. Распакуй архив.
2. Открой index.html в браузере.
3. Для публикации загрузи все файлы в один GitHub-репозиторий.

Важно:
Это front-end демо. Формы не отправляют реальные заявки, оплата и наличие билетов не подключены.
Фото загружаются с Unsplash, Google Fonts — с Google Fonts, поэтому для них нужен интернет.
